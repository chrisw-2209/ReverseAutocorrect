Finds out what words can be accidently spelt from an input word using adjacent keys on a keyboard. Some names can produce unfortnate errors, for example conor and vomit, gary and fart

Adjacent keys are any keys that are touching another key, only letters are used

words_alpha.txt is availble from https://github.com/dwyl/english-words

Run the code and type in a name or word (lower case only) and it will return a list of words that could be spelt using the adjacent keys.
